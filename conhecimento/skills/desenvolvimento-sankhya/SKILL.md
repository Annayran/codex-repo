# Desenvolvimento Sankhya

1. Confirme a raiz Git, a branch, a origem sanitizada e o status. Leia o AGENTS.md aplicável e o perfil existente do projeto.
2. Identifique a área da mudança. Procure os pontos de entrada, símbolos e metadados antes de abrir arquivos. Consulte somente as referências necessárias.
3. Preserve JDK, SDK, ferramentas de build, contratos Java e IDs de metadados. Faça a menor alteração que cubra o fluxo de uso.
4. Para mudanças no banco, prepare implantação, validação e rollback. Execute mudanças de ambiente apenas dentro da autorização disponível.
5. Valide o diff e execute os testes ou builds proporcionais. Registre arquitetura, decisões e problemas conhecidos junto à fonte.

Esta versão foi adaptada para uso fora do ambiente local.
