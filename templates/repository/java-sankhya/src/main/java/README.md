# Código Java

Crie o pacote-base `br.com.zaya.<cliente>.<solucao>` e somente as subdivisões
necessárias conforme `standards/mvc.md`:

```text
controller/
model/dto/
model/entity/
model/repository/
model/service/
view/
sankhya/actions/
sankhya/events/
sankhya/schedulers/
shared/
```

Não crie pacotes vazios. Rotinas sem interface podem omitir `view`.

Remova este arquivo quando o primeiro pacote Java for criado.
