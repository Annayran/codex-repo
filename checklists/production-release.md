# Checklist de publicação em produção

- [ ] Aprovações técnica e funcional registradas.
- [ ] Versão/tag e artefato identificados.
- [ ] Backup e rollback validados.
- [ ] Ordem de publicação documentada.
- [ ] Dependências e janela confirmadas.
- [ ] Scripts de banco revisados.
- [ ] Smoke test definido.
- [ ] Monitoramento pós-publicação definido.
- [ ] Comunicação e responsáveis confirmados.
