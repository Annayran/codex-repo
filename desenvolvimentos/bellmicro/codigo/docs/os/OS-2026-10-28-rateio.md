## ENTREGÁVEL

Desenvolvida a integração do dashboard de rateio de despesas com as ações Java
do Financeiro, utilizando o componente HTML5 315 e a página RateioDespesas.jsp.
Separada a abertura do modal pelo JavaScript das operações de consulta,
simulação e recálculo no backend, mantendo a entrada de efetivação bloqueada
enquanto o serviço financeiro real não estiver implementado.

Adaptado o dashboard enviado pelo cliente, preservando o layout e organizando
JSP, JavaScript e CSS. Aplicado o padrão de abertura do modal da TOP Nutri e
organização de interface baseada na referência MA Hospitalar. Ajustados o
carregamento do React no ambiente Sankhya e o empacotamento de recursos para
tratar os problemas de tela branca e abertura do componente.

Implementada a consulta da ficha do título selecionado por NUFIN e das
sugestões de empresas e centros de resultado, com dados de TGFFIN, TSIEMP,
TGFPAR e TSICUS. Preparados os pacotes Java e HTML5 para continuidade da
homologação.

## VALIDAÇÃO

Build com SDK Sankhya e 113 cenários Java aprovados ao final da etapa.
Compilação do JSP para Java 8 sem erros e testes locais de navegador cobrindo
launcher, iframe, seleção de título, recursos incorporados e integração por
transporte simulado. Layout/CSS original conferidos.

Os testes locais não constituem aceite do fluxo financeiro no ambiente.
Os sintomas relatados pelo cliente foram tratados durante o apoio à
homologação, sem confirmação de conclusão integral ou implantação por esta sessão.
