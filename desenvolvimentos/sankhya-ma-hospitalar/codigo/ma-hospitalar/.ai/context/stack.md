# Stack Técnica

- Java 8, Gradle, JUnit 5.
- Sankhya 4.35, Jape/JdbcWrapper e ScheduledAction.
- Oracle SQL.
- Jackson 2.17.
- JSP/JSTL com `snk:query`, CSS e JavaScript.

## Comandos Úteis

`gradlew.bat clean test genesisPackage`
