# Atualizar Contexto do Projeto

Atualize os arquivos em `/.ai/context` e, se necessario, `/.ai/sankhya` com o estado atual do projeto.

Regras:

- Nao alterar codigo-fonte da aplicacao.
- Remover redundancias.
- Preservar apenas informacoes uteis para retomada futura.
- Nao inventar informacoes.
- Marcar incertezas como **A confirmar**.
- Preservar decisoes tecnicas ainda validas.

Atualize:

- `/.ai/context/checkpoint.md`
- `/.ai/context/current-sprint.md`
- `/.ai/context/decisions.md`, se houver nova decisao
- `/.ai/context/known-issues.md`, se houver novos problemas
- outros arquivos de contexto/sankhya se houver regra desatualizada.

Ao final, listar arquivos alterados e principais mudancas.
