# Merge Request

## Obrigatória

Toda mudança revisável deve possuir objetivo, contexto, escopo, testes, riscos e rollback. Mudanças de banco devem incluir deploy, validação e rollback. Alterações Sankhya devem registrar impactos funcionais relevantes.

Use `templates/merge-request/Default.md` como base. Evidências não podem expor dados pessoais ou credenciais.

## Recomendada

Manter a Merge Request pequena, abrir como Draft durante o desenvolvimento e separar alterações mecânicas de mudanças funcionais.

Regras de quantidade mínima de aprovadores: **Pendente de validação pela equipe**.
