# Conhecimento local do projeto

## Obrigatória

O projeto pode manter estes documentos compactos:

    docs/zaya/
    ├── project-profile.md
    ├── architecture.md
    ├── decisions.md
    └── known-issues.md

- project-profile.md: fatos técnicos gerados e fingerprint de freshness.
- architecture.md: componentes, integrações e restrições desta solução.
- decisions.md: decisões confirmadas, motivação, impacto e rollback.
- known-issues.md: problemas reproduzidos, alcance e solução comprovada.

Não preencha informação fictícia. Não duplique padrões genéricos da biblioteca.
Não promova dados de cliente para zaya-engineering.
