# Checklist de dashboard

- [ ] Parâmetros, aliases e permissões identificados.
- [ ] Consultas avaliadas para cardinalidade e desempenho.
- [ ] Estados vazio, erro e grande volume testados.
- [ ] Frontend não contém credenciais ou regra crítica exclusiva.
- [ ] JSP, HTML5, JavaScript, CSS e SQL compatíveis.
- [ ] Publicação e rollback documentados.
